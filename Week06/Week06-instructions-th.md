## Logic ที่ต้อง implement

1. input ทุกตัวต้องผ่าน `TryParse` (`int`, `double`, `char` ตามที่เหมาะกับเกมของคุณ) — ห้ามใช้ `Parse` หรือ `Convert`
2. ตรวจ input ที่ผิด (พิมพ์ตัวหนังสือแทนตัวเลข, กด Enter เปล่า, ค่านอกช่วงที่เกมรับได้) แล้วแสดงข้อความ ไม่ crash
3. ใช้ `if` (รวมถึง `else if` / `else` ตามที่เกมต้องการ) แยก branch ให้ input ที่ต่างกันเจอผลลัพธ์ที่ต่างกัน — จะมีกี่ case ก็ได้
4. ทุก `if` / `else if` / `else` ต้องมี `{ }` แม้มีบรรทัดเดียว
5. ข้อความใน Console เป็นภาษาอังกฤษล้วน
6. ทดสอบให้ครบทุก branch (แต่ละ branch อย่างน้อย 1 รอบ)

ยังไม่ต้องใช้ `switch`, loop และ method ที่เขียนเอง (ยังไม่ได้เรียน)

## Game Context

เกมตัดสินใจจาก input ของผู้เล่นตลอดเวลา — เลือกเมนูต่อสู้ ใส่จำนวนที่จะซื้อในร้านค้า ตอบตัวเลือกบทสนทนา — และแต่ละครั้งเกมต้องแยกได้ว่าเกิดอะไรขึ้นและเกิดกับใคร ถ้าผู้เล่นพิมพ์ผิดแล้วเกม crash ก็เป็นบั๊กที่ต้องแก้ทันที และถ้าเงื่อนไขเขียนผิดจนผู้เล่นใส่ค่าถูกแต่เกมบอกว่าผิด ก็เป็นบั๊กที่ผู้เล่นเจอได้ตั้งแต่นาทีแรก

## Implementation Hint

`else if` ถูกเช็คจากบนลงล่าง **กิ่งแรกที่เป็นจริงเท่านั้นที่ทำงาน** กิ่งที่เหลือถูกข้าม

**แบบเมนู** — ผู้เล่นเลือกจากตัวเลือก (ตัวอย่างเมนูตัวเลข; ถ้าใช้ตัวอักษรก็เปลี่ยนเป็น `char.TryParse` และ `'A'`):

```csharp
int.TryParse(Console.ReadLine(), out int choice);

if (choice == 1)
{
    // branch 1
}
else if (choice == 2)
{
    // branch 2
}
else
{
    // ที่เหลือทั้งหมด = input ไม่ถูกต้อง (TryParse ล้มเหลวได้ค่า 0 ซึ่งไม่ตรงกับ 1 หรือ 2 จึงมาที่นี่)
}
```

**แบบใส่ค่า** — ผู้เล่นใส่ตัวเลข แล้วเกมตัดสินตามค่า เช็คว่า parse ได้ **และ** ค่าอยู่ในช่วงที่ยอมรับก่อน:

```csharp
bool hpOk = int.TryParse(Console.ReadLine(), out int heroHp);

if (!hpOk || heroHp <= 0)
{
    // input ไม่ถูกต้อง
}
else if (heroHp >= 50)
{
    // branch แข็งแรง
}
else
{
    // branch อ่อนแอ
}
```

ถ้า `0` เป็นค่าที่ใช้ได้ในเกมของคุณ ต้องใช้ `bool` เช็คผล `TryParse` แบบนี้ เพราะ `0` จาก parse ล้มเหลวกับ `0` ที่ผู้เล่นพิมพ์แยกกันไม่ออก และ `TryParse` ที่ล้มเหลวจะให้ตัวแปรที่ `out` เป็นค่าเริ่มต้น (`int` เป็น `0`, `char` เป็น `'\0'`)

**สิ่งที่พลาดกันบ่อย** (ทดสอบคอมไพล์แล้ว):

- `if (choice = 1)` → error **CS0029** (`=` คือกำหนดค่า ใช้ `==` เพื่อเปรียบเทียบ)
- ตัวอักษรเดี่ยวใช้ `'B'` (single quote) ไม่ใช่ `"B"` → `choice == "B"` เป็น error **CS0019**
- `choice == 'a' || 'A'` → error **CS0019** ต้องเขียน `choice ==` ซ้ำทุกครั้ง: `choice == 'a' || choice == 'A'`
- `choice == 2` เมื่อ `choice` เป็น `char` **คอมไพล์ผ่านแต่ไม่เคยเป็นจริง** เพราะเทียบกับตัวอักษรรหัส 2 ที่พิมพ์ไม่ได้ ไม่ใช่เลข 2 บนคีย์บอร์ด ต้องเขียน `'2'`
- เช็ค input ผิด **ก่อน** ด้วยการต่อ `!=` ต้องใช้ `&&` ไม่ใช่ `||`: `choice != 'A' && choice != 'B'` ถูก แต่ `choice != 'A' || choice != 'B'` **เป็นจริงทุกครั้ง** (ตัวอักษรเดียวไม่มีทางเท่ากับทั้ง `'A'` และ `'B'`) ทำให้ทุก input ถูกมองว่าผิด — ถ้าไม่แน่ใจ ให้ใช้แบบเมนูด้านบนที่ `else` ท้ายสุดรับ input ผิดทั้งหมด
