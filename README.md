# GI113-2026-Course

Repository เนื้อหาการสอนของวิชา **GI113 Computer Programming (GI)** ภาคเรียนที่ 1/2569 — เก็บโจทย์ Lab และเอกสารประกอบการสอนของแต่ละสัปดาห์ไว้ที่นี่

⚠️ **Repo นี้เป็นของอาจารย์ผู้สอน สำหรับให้นักศึกษาเข้ามาอ่านเท่านั้น** ถ้าเป็นงานที่นักศึกษาต้องส่ง ให้ทำใน repo ของตัวเอง (`GI113-2026-<รหัสนักศึกษา>` ที่สร้างจาก [`GI113-2026-Template`](https://github.com/owen-santiphap/GI113-2026-Template))

## โครงสร้าง

แต่ละสัปดาห์มีโฟลเดอร์ของตัวเอง ชื่อ `WeekNN` (เลขสองหลัก) และมี `README.md` อยู่ข้างในเป็นโจทย์/เนื้อหาของสัปดาห์นั้น — เปิดโฟลเดอร์แล้ว GitHub จะโชว์ README ให้อ่านทันทีโดยไม่ต้องกดเข้าไฟล์เพิ่ม

```
GI113-2026-Course/
├── Week02/
│   └── README.md   ← Lab 2
├── Week03/
│   └── README.md   ← (จะตามมา)
└── ...
```

## สัปดาห์ที่มีเนื้อหาแล้ว

| สัปดาห์ | เนื้อหา |
|---|---|
| [Week02](./Week02) | Lab 2 — Kirin's Status Report + เกมของคุณเอง (ตัวแปร, ชนิดข้อมูล 6 แบบ, string interpolation, Version Control) |

## ถ้าหาโจทย์ Lab สัปดาห์นี้ไม่เจอ

เข้าโฟลเดอร์ `WeekNN` ของสัปดาห์นั้นตรงๆ (กด "Go to file" พิมพ์เลขสัปดาห์ก็ได้) — README ในนั้นจะมีทุกอย่างที่ต้องรู้ รวมถึงขั้นตอนสำหรับคนที่ไม่ได้เข้าคาบด้วย
