## 📋 Part A — Kirin's Status Report

**วัตถุประสงค์**

ฝึกประกาศตัวแปรครบทั้ง 6 ชนิดข้อมูล และคำนวณด้วยลำดับการทำงานที่ถูกต้อง (คูณก่อนหาร) เพื่อเลี่ยงกับดัก int หารกันแล้วปัดทิ้งที่เจอในคาบ

**Variables** (ประกาศด้วยชื่อและค่าตามนี้เป๊ะ — ห้ามเปลี่ยน เพราะสคริปต์ตรวจงานจะเทียบผลลัพธ์แบบ diff):

```csharp
string bossName = "Kirin";
char rank = 'S';
int level = 7;
int maxHp = 240;
int currentHp = 175;
float attackPower = 42.5f;
double critMultiplier = 1.75;
bool isBoss = true;
```

**Logic ที่ต้อง implement**

1. พิมพ์หัวข้อ `===== BOSS STATUS: INITIAL =====`
2. พิมพ์ค่าตัวแปรทั้ง 8 ตัว **ทีละบรรทัด** โดยมี label กำกับ (ดู Test Cases ด้านล่างเป็นตัวอย่างการจัดข้อความ)
3. พิมพ์บรรทัดว่าง 1 บรรทัด (ใช้ `Console.WriteLine();` ไม่ใส่อะไรในวงเล็บ)
4. คำนวณ HP เป็นเปอร์เซ็นต์แล้วเก็บใส่ตัวแปร `int` ชื่อ `hpPercent` — **สูตรต้องเป็น `currentHp * 100 / maxHp`** (คูณก่อนหาร)
5. พิมพ์ `HP Percent: {hpPercent}%`
6. พิมพ์บรรทัดว่าง 1 บรรทัด
7. พิมพ์ `Kirin takes 60 damage!`
8. ลด `currentHp` ลง 60 (`currentHp = currentHp - 60;`)
9. พิมพ์บรรทัดว่าง 1 บรรทัด
10. พิมพ์หัวข้อ `===== BOSS STATUS: AFTER DAMAGE =====`
11. พิมพ์ `HP: {currentHp} / {maxHp}` ด้วยค่า `currentHp` ใหม่
12. คำนวณ HP เปอร์เซ็นต์ใหม่ด้วยสูตรเดียวกับข้อ 4 แล้วพิมพ์ `HP Percent: {ค่าใหม่}%`

กติกา: ทุกบรรทัดที่มีตัวแปรอยู่ในข้อความ ต้องพิมพ์ด้วย string interpolation (`$"..."`) เท่านั้น ห้ามใช้เครื่องหมาย `+` ต่อสตริง

**Test Cases**

Part A ไม่มี input ที่เปลี่ยนค่าได้ — ใช้ตัวแปรคงที่ด้านบนเสมอ และตรวจด้วยการเทียบผลลัพธ์ทั้งโปรแกรมแบบ diff ไม่ใช่ทีละ test case:

| # | เงื่อนไข | Output ที่ต้องได้ |
|---|---|---|
| A.1 | รันด้วยค่าตัวแปรตั้งต้นตามด้านบน | ผลลัพธ์ตรงกับบล็อกด้านล่างทุกตัวอักษร รวมบรรทัดว่าง (ทดสอบรันจริงแล้ว: 16 บรรทัด, บรรทัดว่าง 3 บรรทัด) |

```
===== BOSS STATUS: INITIAL =====
Name: Kirin
Rank: S
Level: 7
HP: 175 / 240
Attack Power: 42.5
Crit Multiplier: 1.75
Is Boss: True

HP Percent: 72%

Kirin takes 60 damage!

===== BOSS STATUS: AFTER DAMAGE =====
HP: 115 / 240
HP Percent: 47%
```

ผลลัพธ์ของ Part B ต้องพิมพ์ต่อจากบรรทัดสุดท้ายนี้ทันที **ห้ามมีบรรทัดว่างคั่นก่อนขึ้น Part B**

**Game Context**

ใช้แสดงแถบเลือดของบอสในเกมต่อสู้ — เกมจริงต้องคำนวณ % เลือดแบบนี้ทุกครั้งที่บอสโดนโจมตี เพื่ออัปเดต HP bar บนจอให้ผู้เล่นเห็น

**Implementation Hint**

```
// ลำดับคูณ-หารมีผลกับ int:
// currentHp * 100 / maxHp   -> ถูก (175*100=17500, 17500/240=72)
// currentHp / maxHp * 100   -> ผิด (175/240=0 ก่อน แล้วค่อยคูณ 100 ยังได้ 0)
//
// float ต้องมี suffix f ต่อท้ายเลข เช่น 42.5f ไม่งั้น compiler error CS0664
// char ใช้ single quote เช่น 'S' — ถ้าใช้ double quote "S" จะกลายเป็น string ทันที
// พิมพ์บรรทัดว่างด้วย Console.WriteLine(); เฉยๆ ไม่ต้องใส่ ""
```

## 🎮 Part B — เกมของคุณเอง

**วัตถุประสงค์**

ออกแบบและใช้ตัวแปรครบทั้ง 6 ชนิดข้อมูลในบริบทเกมของตัวเอง แทนที่จะทำตามสเปกที่กำหนดตายตัวเหมือน Part A

**Logic ที่ต้อง implement**

1. คิดเกม (แนวไหนก็ได้) แล้วสร้างตัวละคร **4 ตัว** โดยแต่ละตัวมี stat **5 อย่าง**
2. ใช้ชนิดข้อมูลให้ครบทั้ง **6 ชนิด** (`int`, `double`, `float`, `char`, `string`, `bool`) กระจายอยู่ใน stat ทั้งหมดของทั้ง 4 ตัวละคร (ไม่ต้องครบทั้ง 6 ชนิดในตัวละครเดียว แต่รวมทั้ง 4 ตัวแล้วต้องครบ)
3. พิมพ์ stat ของแต่ละตัวละครออกจอ ทุกบรรทัดที่มีตัวแปรใช้ string interpolation (`$"..."`) เหมือน Part A

**Test Cases**

ส่วนนี้ไม่ตรวจแบบ diff เป๊ะ (ออกแบบค่า/ธีมเองได้อิสระ) — เกณฑ์คือรันแล้วต้องอ่านออกว่าค่าที่พิมพ์แต่ละบรรทัดคือ stat อะไร ของตัวละครไหน (มี label กำกับครบทุกค่า)

**Game Context**

เลือกธีมเกมเอง เช่น ตัวละครในเกมต่อสู้ / นักเรียนในเกมจำลองโรงเรียน / ตัวละครในเกมทำฟาร์ม — ไม่บังคับตามตัวอย่าง

**Implementation Hint**

```
// โครงพิมพ์ผล 1 ตัวละคร (ปรับ label ตามธีมของตัวเอง)
// Console.WriteLine($"Name: {name}");
// Console.WriteLine($"HP: {hp}");
// Console.WriteLine($"Speed: {speed}");
// ทำซ้ำแบบนี้ให้ครบ 4 ตัวละคร ตัวละ 5 stat
```
